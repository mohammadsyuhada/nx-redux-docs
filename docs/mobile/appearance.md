# Appearance

**Tools → Settings → Appearance** holds the look of the game lists and the
on-screen pad. `A` steps the highlighted row to its next value.

| Setting | Values | Default |
| --- | --- | --- |
| **Game art style** | Thumbnail, Background | Background |
| **Game art width** | 35%, 45%, 55% | 40% |
| **Pad theme** | Charcoal, Retro | Charcoal |

## Game art style

How game art shows in the game lists. See [Artwork](artwork.md) for where the
art comes from.

- **Thumbnail**: the art sits on the right of the list, at the width set by
  **Game art width**, with rounded corners.
- **Background** (default): the art fills the screen behind the list, and the
  list takes 85% of the screen's width.

## Game art width

How much of the screen's width the art takes in the **Thumbnail** style: 35%,
45% or 55%. It has no effect on the **Background** style.

The default is 40%. The first press moves it to 45%.

## Pad theme

The colors of the on-screen pad in portrait, in the menus and in games.

- **Charcoal** (default): the dark pad.
- **Retro**: a light grey body with magenta face buttons.

The landscape button clusters always stay Charcoal. Their opacity is set per
game or console with **Pad Opacity (landscape)** in the in-game
[Frontend](in-game-menu.md#frontend) options, not here.

## About

**Tools → Settings → About** shows two read-only rows: **NX Redux Mobile**
with the app's version, and **Platform**.
