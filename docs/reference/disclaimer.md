# Disclaimer

## AI-assisted development

NX Redux is developed with the help of [Claude](https://claude.ai), Anthropic's
AI model. The code written by the maintainer for this project — the features,
fixes and changes made since forking — is produced by Claude, working from the
maintainer's requirements, direction and iterative feedback. The maintainer
decides what gets built and how it should behave, tests the result on real
hardware, and reviews and ships each change.

The same applies to this documentation site. The pages here are written by
Claude from the maintainer's input and corrections, then checked against the
actual firmware before publishing.

This applies **only** to the maintainer's own contributions. It does **not**
cover:

- **The original NextUI and MinUI code.** Everything inherited from
  [NextUI](https://github.com/LoveRetro/NextUI) and
  [MinUI](https://github.com/shauninman/MinUI) at the time NX Redux was forked
  was written by their respective authors and contributors. See
  [Credits](credits.md).
- **Contributions from other people.** Code and documentation contributed to
  NX Redux by other contributors is their own work, produced however they
  chose to produce it.

or whatever wrote it, is reviewed before release, distributed under the same

terms as any other open-source project. If you find a bug, or a mistake in

[GitHub](https://github.com/mohammadsyuhada/nx-redux/issues) as usual.
