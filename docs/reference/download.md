## Handheld

Custom firmware for the TrimUI Brick, Brick Hammer, Brick Pro, Smart Pro S
and Smart Pro. Releases are packaged per device, so download the zip for
**your exact model**, then follow
[Getting Started](../handheld/getting-started.md) to install it.

## Mobile

NX Redux for Android phones, tablets and Android handhelds (Android 8.0 or
later, arm64). Download the APK, then follow
[Getting Started on Mobile](../mobile/getting-started.md#install) to install
it. Google Play is coming later.
