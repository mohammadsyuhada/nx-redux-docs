## Handheld

Custom firmware for the TrimUI Brick, Brick Hammer, Brick Pro, Smart Pro S
and Smart Pro. Releases are packaged per device, so download the zip for
**your exact model**, then follow
[Getting Started](../handheld/getting-started.md) to install it.

## Mobile

NX Redux Mobile for Android phones, tablets and Android handhelds is
**coming soon**. See
[Getting Started with NX Redux Mobile](../mobile/getting-started.md) for what
is coming.

It will be available from two places: the **GitHub releases** page as an
APK, and **Google Play**.
